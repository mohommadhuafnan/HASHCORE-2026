# SEUSL HASHCORE '26 — Citadel of Innovation
**Faculty of Technology | South Eastern University of Sri Lanka**

Official event website for **HASHCORE '26**, the premier national tech summit, CTF championship, and 24-hour hackathon organized by the **Society of ICT (SICT)** in collaboration with Official Media Partner **Agni Vision**.

---

## 🏛️ Event Highlights & Flagship Tracks

1. **Track 01: CTF & Cybersecurity**
   - Live Jeopardy-style & Attack-Defense cyber arena
   - Binary exploitation, reverse engineering, web security, cryptographic warfare
   - Hands-on Proving Ground Workshop: **October 24, 2026**

2. **Track 02: Software Development & Hackathon**
   - 24-Hour continuous software sprint & AI engineering
   - Real-world enterprise challenges evaluated by industry leaders
   - Workshop & Hackathon Launch: **October 31, 2026**

## ⚡ Tech Stack & Architecture

- **Framework**: React 19 + Vite 8
- **Styling**: Vanilla Cyber-Emerald Glassmorphic Design System
- **Animation Engine**: 240-Frame Interactive 3D Camera Scroll Canvas with LERP Damping
- **Atmosphere**: Dual-flank scroll-reactive dynamic mist & smoke canvas
- **Font Stack**: Syne, Space Grotesk, JetBrains Mono

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation & Run

```bash
# Navigate to the frontend workspace
cd frontend/hashcode

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the Citadel of Innovation.

### Production Build

```bash
npm run build
```
